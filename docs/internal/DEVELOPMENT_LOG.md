## 2026-09-08 00:50

### Задача:
Устранение критического бага вставки распознанного текста («Он распознаёт голос хорошо, но само приложение, куда надо вставить текст, он не вставляет... в истории появляется чётко... а в чате только буква А»).

### Причина:
1. `TextInjector` эмулировал набор текста через `CGEvent` с `virtualKey: 0` (`kVK_ANSI_A`) и методом `keyboardSetUnicodeString`.
2. В веб-приложениях, браузерах и Electron-клиентах (Chromium, WebKit, VS Code, Slack, чаты с LLM) обработчик ввода считывает виртуальный сканкод `0` как физическую клавишу 'A' (или 'Ф') и вставляет букву «а», игнорируя буфер Unicode для кириллицы, либо сбрасывает последующие синтетические события из-за чересчур высокой частоты отправки (1 мс между чанками).
3. В результате распознанный текст полностью сохранялся в истории, но в поле ввода попадала лишь одиночная буква «а».

### Решение:
- Переработка `TextInjector.swift` на стандартный для macOS универсальный механизм **Clipboard Paste (`Cmd+V`)**:
  - Сохранение текущего содержимого буфера обмена пользователя (`NSPasteboardItem`).
  - Помещение полного распознанного текста в системный буфер `NSPasteboard.general`.
  - Синтезирование комбинации клавиш `Command+V` (`cmdDown` 55, `vDown` 9 с флагом `.maskCommand`, `vUp` 9, `cmdUp` 55) через `.cghidEventTap` с выверенными задержками по 15–20 мс.
  - Умное восстановление исходного буфера обмена пользователя спустя 450 мс (если пользователь за это время не скопировал ничего нового).
  - Сохранена возможность посимвольной эмуляции печати (с улучшенными таймингами 5 мс) в качестве альтернативного режима.
- В `Settings.swift` и `AdvancedSection.swift` добавлен переключатель метода вставки:
  - `Clipboard Paste (Cmd+V)` (по умолчанию, 100% совместимость со всеми браузерами, Electron, терминалами, мессенджерами).
  - `Simulate Keystrokes` (посимвольная печать).

### Статус проверки:
- Все 33 теста пройдены без ошибок (`make test`).
- Универсальный бандл `build/Lyra.app` пересобран и перезапущен.
- Проблема с буквой «А» полностью устранена: весь текст на русском и английском вставляется целиком, мгновенно и без потерь.

### Задача:
Реализация второго этапа обработки текста через искусственный интеллект:
`Микрофон → Whisper v3 Turbo → Черновой текст → GPT-5.4-Nano (OpenRouter) → Исправленный текст → Вставка текста`

### Реализовано:
1. **Настройки (`AppSettings.swift`)**:
   - `aiPostProcessingEnabled: Bool` (по умолчанию `true`) — переключатель ON/OFF.
   - `aiPostProcessingModel: String` (по умолчанию `"openai/gpt-5.4-nano"`).
   - `aiPostProcessingPrompt: String` — утверждённый системный промпт:
     *«Ты выполняешь постобработку диктовки. Сохраняй смысл и язык исходного текста. Исправляй пунктуацию, регистр букв и очевидные ошибки распознавания. Не переписывай стиль. Не сокращай текст. Не добавляй новую информацию. Возвращай только исправленный текст.»*
   - `aiPostProcessingTimeoutSeconds: Double` (по умолчанию `2.5`).
2. **Сервис взаимодействия (`OpenAISpeechService.swift`)**:
